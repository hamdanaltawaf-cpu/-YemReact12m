# YemReact — قائمة تدقيق الإطلاق (Launch Checklist)

> افحص كل صندوق قبل الإطلاق العلني. أي ❌ يمنع الإطلاق.

---

## 1. فحص الأمان

- [ ] كل الأسرار (SESSION_SECRET / ADMIN_SECRET / OTP_SALT / IP_SALT / YEMREACT_ADMIN_PASSWORD) قيم قوية مولّدة بـ `openssl rand -hex 32` — لا قيم افتراضية.
- [ ] `NODE_ENV=production` والخادم يقلع بلا تحذير "أسرار افتراضية".
- [ ] HTTPS مفعّل (شهادة TLS) والكوكيز `Secure`.
- [ ] رأس CSP موجود في الاستجابات HTML (`default-src 'self'`).
- [ ] حماية CSRF تعمل (رفض Origin مختلف — اختُبر).
- [ ] Rate limiting على تسجيل الدخول وOTP والرفع والإبلاغ.
- [ ] فحص الملفات (magic bytes + الحجم + المدة + كشف التكرار) مطبق على كل مسارات الرفع.
- [ ] `/api/v1/health` يعيد `ok:true` بكل الفحوص.

## 2. فحص الأداء

- [ ] الصفحة الرئيسية تحمّل < 50KB (HTML+CSS+JS حرجة) على 3G.
- [ ] الصور WebP، الفيديو `preload=metadata`، تحميل كسول مفعّل.
- [ ] PWA مثبّتة: manifest + service worker (cache-first للأصول، network-first للبيانات).
- [ ] فحص المتصفح (ديسكتوب + موبايل) = 0 أخطاء console.

## 3. فحص SEO/OpenGraph

- [ ] صفحة لكل رياكشن بمسار حقيقي `/r/[slug]` (لا hash routing).
- [ ] وسوم OG ديناميكية (عنوان/وصف/صورة) لكل رياكشن.
- [ ] canonical نظيف بلا `.html`.
- [ ] اختبر معاينة المشاركة في واتساب/فيسبوك (مثال: `/r/yr-0001`).
- [ ] `sitemap.xml` أو على الأقل الصفحات قابلة للزحف (إن لم تُضف sitemap، أضفها كتحسين لاحق).

## 4. فحص الحقوق والمحتوى

- [ ] كل رياكشن منشور له `rights_status` موثّق (مرخّص/إذن/مساهمة أصلية).
- [ ] لا محتوى بلا سجل مصدر (مبدأ "مصدر بلا دليل = لا ننشر").
- [ ] مساهمات المستخدمين تتطلب إقرار ملكية (مفعّل).
- [ ] نظام الإبلاغ/Takedown يعمل: إبلاغ → تعليق فوري → مراجعة → حذف/نشر.
- [ ] مكتبة أولية جاهزة (50–100 رياكشن منتقى) قبل الإطلاق.

## 5. فحص النسخ الاحتياطي

- [ ] `./scripts/backup.sh` ينتج نسخة صالحة.
- [ ] جرّبت الاستعادة `./scripts/restore.sh` على بيئة نظيفة ونجحت.
- [ ] cron اليومي مفعّل.
- [ ] مراقب خارجي (UptimeRobot/Healthchecks) يشير إلى `/api/v1/health`.

## 6. فحص PWA

- [ ] التثبيت على الشاشة الرئيسية يعمل (موبايل).
- [ ] الأيقونات (192/512) موجودة وواضحة.
- [ ] العمل دون اتصال جزئي (التصفح من الكاش) يعمل.

## 7. فحص المحتوى الاجتماعي (علامة المحتوى)

- [ ] Bio/صورة الحساب/الغلاف جاهزة (من حزمة الأصول).
- [ ] أول 10 منشورات جاهزة وفق نظام المحتوى (قُصاصة يومية/متى تحتاجها؟/مكتبة الأسبوع).
- [ ] الواترمارك ثابت الحجم/الموضع في كل لقطة.
- [ ] لا Intro قبل أي لقطة (أول فريم = بداية الرياكشن).

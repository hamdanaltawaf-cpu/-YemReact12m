# سجل القرارات المعمارية والمنتجية (Architecture Decision Records)

> هذه الوثيقة مرجع القرارات الكبرى. كل تغيير جوهري يُسجَّل هنا مع تبريره.

## الرؤية والقيمة الجوهرية

> **يمن رياكت هو "قاموس الأمثال المرئية" اليمني:** المكان الذي تروح إليه عندما يكون عندك
> موقف ولا تجد الكلمة — فتجد لقطة جاهزة تقولها عنك، بعين يمنية، تقصّها وتحطّها.

**الخندق التنافسي (Moat) — ثلاث طبقات متراكبة، والكود ليس منها:**
1. المكتبة المنتقاة يدويًا (حكم ذوقي تراكمي).
2. فهرس المواقف (بيانات ملكية: الموقف + الكلمات العامية + المرادفات + السياقات).
3. حلقة "اطلب رياكشن" (الجمهور يموّل الطابور، والمنافس لا ينسخها بلا جمهور).

## المبادئ المعمارية الإلزامية

1. المنتج **محرك بحث عن كلمة بصرية يمنية**، ليس شبكة اجتماعية (لا feed/لايكات/تعليقات).
2. المحتوى والانتقاء أولًا؛ أي ميزة ذكية تُؤجَّل حتى تثبت الحاجة.
3. لا شيء يُنشر آليًا دون مراجعة بشرية.
4. الواترمارك في كل تنزيل = قناة النمو (ثبات الموضع/الحجم، لا تنويع).
5. خفيف وسريع على 3G؛ تجربة الهاتف أولًا.
6. لا ترند علني — البديل: "مختار الأسبوع" (بشري) و"جديد المكتبة".
7. معرّف داخلي UUID + معرّف عرض بشري (YR-####) منفصل، مع slug للـSEO.
8. فصل الطبقات: Repository/Service/Controller؛ لا SQL في الواجهة، لا منطق عمل في الروتات.
9. كل خدمة خارجية (تخزين/بريد/معالجة) خلف interface قابل للتبديل.
10. مصدر حقيقة واحد للعدّادات (أحداث خام → عدّادات مجمّعة بنفس المعاملة).
11. أخطاء موحّدة، لا فشل صامت.
12. لا أسرار افتراضية؛ فحص إجباري عند الإقلاع.
13. RTL واحترام الخصوصية (لا IP خام) من البداية.

## قرارات الهوية (P0)

- المصدر الوحيد للحقيقة البصرية = `YemReact-Brand-v1.0-LOCKED.html`، مترجم إلى
  `src/tokens/design-tokens.js`.
- القيم المعتمدة: `رفض #6E8296`، `حماس #E8712E` (تلغي قيم الدليل المبكر `#5C6B7A` / `#E06A34`).
- "انبهار" ضمن عائلة "استغراب" (لا لون عاشر).
- الواترمارك: تقشّر 9–15% من العرض، زاوية علوية، ظلّ مزدوج، مع قاعدة "قلب الكتلة".

## الحوكمة الحقوقية (فجوة حرجة — تُعالج قبل فتح المساهمات في P5)

- حقل `rights_status` لكل رياكشن: مرخّص / إذن موثّق / مساهمة أصلية / قيد المراجعة / مرفوض.
- سجل مصدر إلزامي (رابط + تاريخ + اسم المراجع) قبل أي نشر.
- إقرار ملكية عند المساهمة + رابط إبلاغ + Takedown (تعليق تلقائي → مراجعة → حذف).

## الأولويات (MoSCoW)

- **Must:** مكتبة منتقاة، بحث بالموقف، معالجة فيديو كاملة، تنزيل مائي، أحداث حقيقية،
  لوحة مسؤول، مساهمات بمراجعة، حسابات OTP، صفحات قانونية، أمان، SEO/OG، أداء 3G.
- **Should:** مجموعات، مختار الأسبوع، كشف تكرار، جودات متعددة، استعلامات فاشلة، شارة
  مساهِم موثوق، إشعارات بريد، PWA.
- **Could:** بحث دلالي (300+)، اقتراح كابشن بالـAI (بيد بشرية)، أدوار editor.
- **Not Now:** تطبيق Native، ترند/لايكات، تعليقات، مجموعات مستخدمين، إعلانات.
